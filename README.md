# 🚀 Getting Started

## Clone

```bash
git clone https://github.com/harish03b/portfolio.git
```

---

## Install

```bash
npm install
```

---

## Start Development Server

```bash
npm run dev
```

---

## Production Build

```bash
npm run build
```

---

## Preview Production Build

```bash
npm run preview
```
